# snip-ocr · 桌面截图工具

系统截图工具的平替，界面采用「校样台 / Proofing Table」视觉系统：主窗口、截图工具栏、贴图、OCR 侧栏与整页设置，浅色/深色跟随系统。

技术栈：Electron 33 + TypeScript(strict) + React 19 + [electron-screenshots](https://github.com/nashaofu/screenshots)（原生采集与遮罩）+ electron-vite + electron-builder。

## 运行

```bash
npm install
npm run icon       # 重新生成安装图标与托盘图标
npm run dev        # 开发模式（vite 热更新 + Electron）
npm run build      # 类型检查 + 打包 out/
npm run selftest   # 打包后跑一遍自动化验收（会真的弹遮罩）
npm run dist       # 只解包，快速验证打包
npm run pack       # 生成安装包 → dist/
```

启动后显示主窗口（`准备好截个图了吗？`），关闭主窗口会隐藏到托盘；托盘菜单：`截图` / `打开主界面` / `设置快捷键…` / `关闭所有贴图 (N)` / `退出`。左键单击托盘图标仍直接截图。

命令行参数：`--settings` 启动后打开设置弹窗；`--hidden` 只留托盘（开机自启使用）；`--selftest` 跑自动化验收后退出。

## 快捷键与操作

| 动作 | 键 |
| --- | --- |
| 唤起截图 | `Alt+A`（默认，可在设置里录制修改） |
| 贴最近一张截图 | `Alt+P`（默认，可在设置里录制修改；取自截图历史最新一条，重启后仍可用） |
| 取消截图 / 关闭侧栏 | `Esc` |
| 复制选区 | 双击选区内部 |
| 关闭贴图 | 双击贴图、悬停右上角 ×、或贴图聚焦时 `Esc` |

快捷键持久化在 `<安装目录>\data\config.json`（Portable 版为便携 exe 旁的 `data\config.json`）。注册失败（被占用）时保留上一个可用值，并在设置里显示红字。

## 截图工具栏（6 按钮）

拖动框选后，选区下方出现：**OCR / 贴图 / 另存为 / 长图 / 取消 / 确定**。

- **贴图**：生成贴图浮窗；与「确定」完全独立。
- **确定**：复制到剪贴板并关闭遮罩。
- **另存为**：系统「另存为」对话框，默认 `yyyyMMddHHmmssSSS.png`，PNG。
- **长图**：进入被动跟随长截图（无需按键，自动到底）。细则见下节。
- **取消**：关闭遮罩（等同 Esc）；长图态下放弃本次采集，且不写剪贴板。
- **OCR**：遮罩保持打开，右侧展开 OCR 侧栏（会自动放到选区对侧）；识别完成后显示可编辑文本、字数与「复制」按钮，用户手动复制。识别中禁用重复点击；关闭侧栏后迟到的结果不会自动重开。识别失败/无文字时侧栏显示错误，不覆盖剪贴板。
- 双击选区内部 = 复制到剪贴板并关闭遮罩。
- 工具栏图标随设置里的「图标定制」切换：默认线框 / DeepSeek 大肥鱼 / 菲比丘比 / 自定义上传。

### 长截图

- 流程：框选固定区域 → 点「长图」；主遮罩收起，只留贴着选区的细边框与 HUD，窗口鼠标穿透、不抢焦点。之后正常用滚轮/触控板滚动页面即可，全程不需要按键或点击。
- 选区透明：跟随态选区内部完全透出真实屏幕（冻结截图只作为数据源留在 DOM，不参与显示），滚动时看到的就是当前页面。
- HUD 按钮：跟随态「完成/取消」与完成态「复制/另存/OCR/关闭」复用截图工具栏同一套样式（同尺寸、圆角、颜色变量与 hover 态）。
- 实时预览：选区外侧自动出现一个细长的预览缩略窗（`pointer-events: none`，严格避开选区；外侧空间不足时自动换到空间更大的一侧并等比缩小），随滚动持续更新已拼接内容，HUD 同步显示「第 N 段 · 高度 px」。
- 采集：后台静默抓取选区；滚动过程中用低分辨率指纹做运动检测，画面停稳且内容确有变化才按原分辨率入栈。入栈帧与普通截图走同一条 canvas 裁剪路径（同一 DPR、同一小数坐标与插值、PNG 无损），单帧像素与普通截图一致。
- 结束：滚到底静止约 1 秒后自动判定到底 → 纵向拼接 → 自动复制到剪贴板；HUD 上仍可点「完成」（立即结束）以及「复制 / 另存 / OCR / 关闭」。
- 拼接：整行灰度指纹多候选打分取最优重叠，容忍平滑滚动、压缩与抗锯齿差异；固定表头只保留一份；左右边缘（滚动条/固定侧栏）不参与匹配。
- 超长：超过 20000 物理像素改为分段导出——复制首段并通知段数，另存按 `-1/-2…` 后缀写出全部段，不丢帧也不报错。
- 限制：仅纵向、仅单屏；中途停顿超过约 1 秒会被判定为到底（需要更多内容时请在停顿前继续滚动）；`Esc`/「取消」丢弃本次采集且不产生剪贴板副作用；普通截图路径不受影响。

## 主窗口与设置

主窗口标题栏左侧为品牌字标与版本号，右侧为设置、电源菜单（隐藏到托盘 / 退出）、最小化、关闭到托盘。首页是一块带裁切标记的截图版面：顶部显示快捷键就绪状态与「本地 OCR · 零联网」，中部有大号「点击截图」按钮、贴图数量/确定复制/贴图快捷键规格条，以及 `贴最近一张` 与 `打开设置` 快捷操作，底部提示「关闭窗口后仍在托盘运行」。右上角齿轮打开主窗内的整页设置，左侧为分类导航，三个分类：

1. **快捷键**：截图快捷键、贴图快捷键（录制 / 应用 / 取消 / 恢复默认；失败时应用禁用，修改组合后可重试）。
2. **通用设置**：开机自启（仅安装版生效）、检查更新（离线显示当前已是最新版本，不伪造更新）。
3. **图标定制**：4 种图标主题 + 顶部工具栏图标预览，自定义图标支持 PNG/JPG/WebP（最大 5MB），会保存到 `<安装目录>\data\icons\custom.png`。

## 贴图

- 「贴图」或 `Alt+P` 后生成 `snip-pin` 浮窗：无边框、透明、始终置顶、不进任务栏与 Alt+Tab（Windows 用 `type: 'toolbar'` → `WS_EX_TOOLWINDOW`）。
- 内容区只有截图本身（独立 [pin.html](src/renderer/pin.html) + 原生 `<img>`），边框用 `box-shadow` 叠在图片上，不占布局。
- 初始尺寸按 `图片物理像素 / scaleFactor` 换算成 DIP，125%/150% 下内容区 × scaleFactor = 截图像素。
- 拖拽移动；8 向拖边缘/角调整窗口大小（悬停显示四角手柄）；滚轮只缩放窗口内图片内容（0.25×–8×，以光标为锚点），标题条显示百分比，`Ctrl+0` 回到 100%；双击/Esc 关闭；悬停右上角 × 单张关闭；多张并存；托盘「关闭所有贴图 (N)」一次清空。
- 图片按窗口等比完整显示，边框与图片共用同一组 DPR 取整后的几何值，窗口比例不一致或滚轮缩放时也紧贴图片；缩小由浏览器按目标设备像素重新栅格化（不使用 `will-change` 缓存层拉伸），保持清晰。
- 悬停时显示「贴图窗口」标题条（覆盖在图片上，不挤占布局）。
- 图片经临时 PNG 落盘（`<安装目录>\data\pins\pin-*.png`）后以 `snip-pin://` 协议传给贴图页，IPC 不传大数组；关闭时异步删除，启动时清理残留。
- **运行数据不落 %APPDATA%**：打包态 `userData` 指向程序目录 `data\`；安装目录不可写时回退 `%APPDATA%\snip-ocr`，卸载器兜底清理；旧数据首次启动迁移后删除。

### 截图历史

- 四种成功出口各记录一条：复制到剪贴板（`copy`）、另存为（`save`）、贴图（`pin`）、长图完成（`longshot`），条目带来源字段；原图 + 缩略图 + 创建时间 + 原始像素尺寸。取消、失败不记录；从历史重新贴出、复制、另存不会重复记录；长图完成后对长图另存不再重复记录。
- 数据目录为 `<userData>\pin-history\`（打包态即安装目录 `data\pin-history\`；数据目录不可写回退到 `%APPDATA%\snip-ocr\pin-history\`），内含 `history-*.png` 原图、`history-*-thumb.png` 缩略图、`history.json` 索引。与 `data\pins\` 临时贴图分开，启动时只清理 `data\pins\`，历史保留。
- 默认保留最近 50 条，超出按最旧淘汰并删除对应文件；不提供设置项，重启后仍在。
- 主窗首页「截图历史」按钮打开列表：展示缩略图、来源、时间、尺寸，支持点击重新贴出（落在当前鼠标所在显示器）、复制、另存为、单条删除、清空全部。

## 本地识字（OCR）

- 使用 Windows.Media.Ocr，全程本地、零网络、零新增依赖；识别语言由系统 OCR 语言包决定（本机 `zh-Hans-CN`），无语言包时明确报错。
- 系统同时装有 `en-US` 时启用双引擎：同一张图分别用中文与英文各识别一次，再按 `OcrLine.Words` 的 `BoundingRect` 逐行对齐合并——纯中文行用中文结果，纯拉丁行用英文结果，中英混排行按词框把拉丁误读替换为英文结果。没有 `en-US` 时静默回退单引擎，不报错、不提示安装。
- 图像预处理按尺寸自适应：像素数 > 100 万的大视野、以及 ≤400×80 的微裁切保持原始尺寸（放大反而掉字），其余小字号裁切放大 2×（放大后最长边仍受 4000 px 上限保护）。
- 遮罩内 OCR 侧栏：可编辑文本、实时字数、手动复制、关闭；再次 OCR 覆盖内容。
- 识别经 PowerShell/WinRT 桥执行，单任务串行、15 秒超时；临时图在 `<安装目录>\data\ocr\`，结束即删。

## 多显示器与高 DPI

- 遮罩窗按鼠标所在显示器的 DIP 边界创建；取图用 `node-screenshots` 原生物理分辨率采集，失败回退 `desktopCapturer`。
- 裁剪按「原图像素 / 视口 CSS 像素」换算；自检断言 `裁剪像素宽 = 选区 DIP 宽 × scaleFactor`（1.25 屏实测 664 → 830，误差 0）。
- 贴图位置 = 显示器 DIP 原点 + 选区偏移，尺寸 = 图片物理像素 / scaleFactor；100/125/150/200% 均有断言，1.25 屏实测 1:1。

## 已知限制

1. **Alt+A 可能被其它应用占用**（本机实测被占用）；在设置里换 `Ctrl+Alt+A` / `Ctrl+Shift+A` 等即可。
2. 只能截鼠标所在显示器，不支持一次跨多屏拉框。
3. 工具栏/侧栏通过注入 `electron-screenshots` 页面实现（库没有扩展点）；升级该库大版本需重新核对选择器与按钮 title。
4. `Esc` 取消依赖遮罩持有键盘焦点；焦点被系统弹窗抢走时先点一下遮罩。OCR 侧栏打开时 Esc 只关侧栏。
5. 保存对话框默认名由库决定，不是自定义时间戳格式。
6. 无标注；截图历史保留最近 50 条（见上节）；检查更新为离线「已是最新」，没有真实更新服务。
7. 贴图不做鼠标穿透、分组、透明度、旋转；贴图不持久化，退出即消失。
8. 分数缩放下贴图落点可能有 ≤2 DIP 偏移；图片尺寸严格 1:1；拖拽中高度可能瞬时 +1 DIP，松手自动校正。
9. 贴图跨不同缩放比显示器拖动可能出现轻微重采样。
10. 未做代码签名，Windows 会弹 SmartScreen；macOS 未公证。
11. 开机自启仅安装版生效；开发模式会提示不支持。
12. OCR 依赖系统语言包，小字/艺术字/手写/复杂排版会出错；中英混排时英文单词仍可能被中文引擎误读（装 `en-US` 语言包可启用双引擎缓解），关键文字请复核。
13. 打包环境坑：索引器可能锁住 `app.asar` 导致 `EPERM/EBUSY`（输出到工作区外再拷回）；无外网时 `@electron/get` 会卡在校验，需要 `ELECTRON_MIRROR`（本机用 `https://npmmirror.com/mirrors/electron/`）。
14. 长截图仅支持纵向滚动与单屏固定选区；横向滚动、跨屏、滚动中改变缩放比，以及透视/全屏独占应用均不支持。
15. 长截图靠静止判定采帧：滚动过快或帧间位移超过一屏会产生缝隙；固定表头只保留一份，固定侧栏/懒加载/动画仍可能造成重复或错位。
16. 长截图在停顿约 1 秒后自动结束；超长结果按 20000 物理像素分段导出，剪贴板只放首段，其余段需用「另存」。
17. 长截图实时预览为降采样缩略图（宽度 180 DIP、随选区外侧空间自动缩放），只反映已入栈内容，滚动中会有约 0.2–0.4 秒滞后。
18. 4K@2x 下静默抓帧单帧约 110–130ms，跟随帧率约 6–8fps（按低分辨率运动检测 + 停顿后全分辨率降级实现）；跟随手感与 4K 表现仅经手工验证。
