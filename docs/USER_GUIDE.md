# snip-ocr 用户手册

适用版本：桌面版 0.1.0（Windows 实测）
界面采用「校样台 / Proofing Table」视觉系统：主窗口、截图工具栏、贴图、OCR 侧栏与整页设置；浅色/深色跟随系统。

---

## 1. 产品简介

snip-ocr 是**完全离线**的 Windows 桌面截图工具：主窗口 + 托盘常驻，按快捷键框选，松手后可复制、存 PNG、贴成置顶浮窗，或本地识图取字。

全程不访问网络、不需要账号，配置只写本地 `data\config.json`。

### 不适用场景

- 需要标注（箭头/马赛克/文字）、自动更新：不提供；截图历史保留最近 50 条，见 3.6。
- 手写体、竖排、低对比度艺术字：系统 OCR 不擅长，需人工复核。
- 跨多显示器一次拉框：不支持，只能截鼠标所在屏。
- 中译英：离线翻译插件只支持英译中，中译英不提供。

## 2. 安装与构建

### 2.1 直接安装

1. 双击 `snip-ocr-Setup-0.1.0.exe`，或运行免安装版 `snip-ocr-Portable-0.1.0.exe`。
2. 首次运行 Windows SmartScreen 提示时点「更多信息 → 仍要运行」（未签名，属预期）。
3. 启动后显示主窗口；关闭主窗口会隐藏到托盘。彻底退出可用右上角电源菜单，或托盘右键菜单。

### 2.2 源码构建

```bash
npm install
npm run icon       # 重新生成安装图标与托盘图标
npm run dev        # 开发模式，显示主窗口
npm run build      # 类型检查 + 构建 out/
npm run selftest   # 自动化验收（会真实弹遮罩）
npm run dist       # 只解包，快速验证打包
npm run pack       # 安装包输出到 dist/
```

**预期结果**：`npm run selftest` 末行 `[selftest] ALL PASS`（开发态实测 135 PASS + 9 INFO；打包版 `snip-ocr.exe --selftest` 实测 136 PASS + 9 INFO，0 FAIL。其中 1 条 INFO 是 `Alt+A` 被其它应用占用时的注册结果）。

### 2.3 可选翻译插件（英译中）

安装包不含翻译引擎。需要「英译中」时，把 `translate-locally` 目录放到 `<安装目录>\data\plugins\translate-locally\`（便携版放到 exe 旁的 `data\plugins\`），目录结构与文件校验见该目录内 `README.txt` 和项目 README。

- 仅支持**英译中**；中译英按钮置灰并提示「暂不支持中译英」。
- 全程离线：只调用本地 exe，不会下载模型、不会自动更新。
- 未安装时 OCR 侧栏的「译成中文」按钮置灰，状态行显示应放置的路径。

## 3. 快速开始

### 3.1 截图并复制

1. 主窗口点「点击截图」，或按 `Alt+A`。
2. 拖动框选，松开。
3. 工具栏出现：**OCR / 贴图 / 另存为 / 长图 / 取消 / 确定**。
4. 双击选区内部即可复制到剪贴板；也可在工具栏点「取消」关闭。

### 3.2 保存

框选后点「另存为」→ 系统对话框 → 默认文件名是时间戳 PNG。

### 3.3 贴图

- 点「贴图」生成贴图浮窗；「确定」只复制到剪贴板并关闭遮罩。也可用 `Alt+P` 贴最近一张截图（取截图历史最新一条，重启后仍可用；历史为空时会提示先截一张）。
- 初始尺寸与截图 1:1；拖拽移动、8 向改窗口大小、滚轮缩放窗口内图片、双击/Esc/悬停 × 关闭；多张可并存。

### 3.4 OCR 取字

1. 框选后点「OCR」。
2. 遮罩保持打开，OCR 侧栏会自动出现在选区的另一侧，先显示「正在识别中…」；识别中不能重复点 OCR。侧栏可按住标题条拖动到任意位置（拖动后本次截图内不再自动挪动，下一次截图重新自动定位，且始终限制在屏幕内）。
3. 完成后文字进入可编辑文本框，底部显示字数；点「复制」才写入剪贴板。
4. 若翻译插件已安装且识别语种为英文，点侧栏底部「译成中文」；译文出现在文字框下方的只读区，原文保留可继续编辑。翻译只在本机进行，单次最长 30 秒、文本上限 5000 字；失败时状态行显示原因且不覆盖原文。中译英不支持。
5. 点 × 或按 Esc 关闭侧栏（遮罩仍在，可继续另存/确定/取消）。

### 3.5 长截图

1. 框选固定区域后点「长图」。主遮罩收起，选区内部透出真实屏幕（只留一圈细边框和一个 HUD，不再显示冻结画面）；此时窗口鼠标穿透、不抢焦点。
2. 选区外侧会出现一个细长的实时预览窗（等比缩略图，鼠标穿透；外侧空间不足时自动换到空间更大的一侧并缩小，绝不会盖住选区），随滚动持续更新已拼接内容；HUD 同时显示「第 N 段 · 高度 px」。
3. 直接用滚轮/触控板把页面往下滚，**不需要再按任何键**。程序在后台静默抓取选区：滚动时只做低分辨率运动检测，画面停稳且内容有变化才按原分辨率入栈。入栈帧与普通截图走同一条裁剪路径，单帧像素与普通截图一致。
4. 滚到底并静止约 1 秒后自动判定「到底」→ 纵向拼接 → 自动复制到剪贴板。
5. 完成态 HUD 上还可以点「复制 / 另存 / OCR / 关闭」；跟随中也可点「完成」立即结束，或点「取消」（等同 `Esc`，丢弃本次采集且不写剪贴板）。两处 HUD 按钮与截图工具栏同款（同尺寸、圆角、配色与 hover 态）。

拼接使用整行灰度指纹多候选打分，能容忍平滑滚动、压缩与抗锯齿差异；固定表头只保留一份，左右边缘（滚动条/固定侧栏）不参与匹配。总高度超过 20000 物理像素时改为分段导出：复制首段并在通知里提示段数，另存按 `-1/-2…` 后缀写出全部段，不丢帧也不报错。

限制：仅纵向、仅单屏；中途停顿超过约 1 秒会被判定为到底，需要更多内容时请在停顿前继续滚动。

### 3.6 截图历史

- 四种成功出口各记录一条：复制到剪贴板、另存为、贴图、长图完成；每条标注来源、时间与像素尺寸。取消或失败的截图不会记录；从历史重新贴出、复制、另存都不会新增记录（长图完成后对长图另存也不重复记）。
- 默认保留最近 50 条，超出淘汰最旧（连同文件一起删除）。
- 主窗首页点「截图历史」打开列表：可点击缩略图重新贴出、复制、另存为、单条删除或清空全部。
- 数据在 `data\pin-history\`，与 `data\pins\` 临时图分开；退出应用不会清空，重启后仍在。

## 4. 主窗口与设置

主窗口标题栏左侧为品牌字标与版本号；右侧依次为设置、电源菜单（隐藏到托盘 / 退出）、最小化、关闭到托盘。首页显示快捷键就绪状态、本地 OCR/零联网提示、贴图数量/确定复制/贴图快捷键规格条，并提供「贴最近一张」「打开设置」和底部托盘提示。

设置以主窗内整页打开，左侧为分类导航，分三个分类：

1. **快捷键**：截图快捷键 / 贴图快捷键；录制后点「应用」，失败会显示红字并禁用该组合的应用按钮；可恢复默认。
2. **通用设置**：开机自启（仅安装版生效）、检查更新（离线显示当前已是最新版本）。
3. **图标定制**：默认线框 / DeepSeek 大肥鱼 / 菲比丘比 / 自定义上传（PNG/JPG/WebP，≤5MB）。顶部有 6 图标工具栏预览，可一键恢复默认。

## 5. 贴图操作

| 操作 | 方式 |
| --- | --- |
| 移动 | 拖动浮窗任意位置 |
| 调整窗口大小 | 拖 8 个边缘/角 |
| 缩放图片内容 | 滚轮（0.25×–8×，以光标为锚点），顶部测量条显示尺寸与百分比；`Ctrl+0` 回到 100% |
| 关闭单张 | 悬停点右上角 ×（默认可见），或双击，或聚焦时按 Esc |
| 关闭全部 | 托盘右键「关闭所有贴图 (N)」 |
| 多张并存 | 支持；每张有独立 × |

悬停时显示 PIN 测量条（尺寸、缩放百分比与关闭入口）；贴图不持久化，退出应用即消失，临时 PNG 会清理。窗口比例与图片不一致时图片等比完整显示、边框紧贴图片；缩小按设备像素重新采样，保持清晰。

## 6. 快捷键

| 动作 | 键 | 可修改 |
| --- | --- | --- |
| 唤起截图 | `Alt+A` | 设置 → 快捷键 |
| 贴最近一张截图（截图历史最新一条） | `Alt+P` | 设置 → 快捷键 |
| 取消截图 / 关闭侧栏 | `Esc` | 固定 |
| 复制选区 | 双击选区内部 | 固定 |
| 关闭贴图 | 双击 / × / 聚焦时 Esc | 固定 |

快捷键写入 `<安装目录>\data\config.json`（Portable 为 exe 旁 `data\config.json`）。

## 7. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Alt+A` 没反应 | 被其它应用占用 | 设置里换 `Ctrl+Alt+A` 等 |
| 主窗口找不到 | 被关闭到托盘 | 托盘右键「打开主界面」 |
| 托盘图标找不到 | 被 Windows 折叠 | 展开通知区/设为常驻 |
| OCR 失败/乱码 | 系统无语言包，或小字/艺术字 | 安装系统 OCR 语言；放大后重试；人工复核 |
| 识字后剪贴板没变 | 设计如此，侧栏不自动复制 | 在侧栏点「复制」 |
| 确定后没有贴图 | 「确定」只负责复制，贴图是独立动作 | 点工具栏「贴图」，或按 `Alt+P` |
| 卸载后 C 盘残留 | 正常不残留 | 安装目录（含 data）与 `%APPDATA%\snip-ocr` 都会被卸载器清理 |

## 8. 安全与限制

- 不访问网络、无账号、无授权校验；OCR 本地执行，不上传截图。
- 剪贴板可能被其它应用读取；复制敏感内容后请及时清理。
- 只能截鼠标所在显示器；无标注、截图历史保留最近 50 条、无自动更新。
- 检查更新为离线「当前已是最新」，不伪造新版本。
- 未签名：Windows SmartScreen、macOS 未公证。
- OCR 依赖系统语言包，关键文字需复核。
- 翻译插件是可选、用户手动安装的本地 exe，仅英译中；主包不含插件，不联网、不下载模型、不自动更新。
- 分数缩放下贴图落点可能偏移 ≤2 DIP；图片尺寸严格 1:1。

## 9. 附录

### 9.1 配置文件

路径：`<安装目录>\data\config.json`（Portable 为便携 exe 旁的 `data\config.json`）

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `hotkey` | string | `Alt+A` | 截图快捷键 |
| `pinHotkey` | string | `Alt+P` | 贴最近一张截图（截图历史最新一条） |
| `iconTheme` | string | `default` | `default`/`deepseek`/`chibi`/`custom` |

### 9.2 命令

| 命令 | 作用 |
| --- | --- |
| `npm run icon` | 重新生成安装图标与托盘图标 |
| `npm run dev` | 开发模式（主窗口） |
| `npm run build` | 类型检查 + 构建 |
| `npm run selftest` | 自动化验收 |
| `npm run dist` | 只解包，快速验证打包 |
| `npm run pack` | 安装包（→ dist/） |
| `snip-ocr.exe --settings` | 启动并打开设置 |
| `snip-ocr.exe --selftest` | 对打包产物验收 |

### 9.3 反馈

问题反馈请附：版本号、Windows 缩放比例、`npm run selftest` 末行输出；OCR 问题另附截图样张与系统语言。
