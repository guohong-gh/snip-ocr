# snip-ocr 用户手册

适用版本：桌面版 0.1.0（Windows 实测）
界面采用「校样台 / Proofing Table」视觉系统：主窗口、截图工具栏、贴图、OCR 侧栏与整页设置；浅色/深色跟随系统。

---

## 1. 产品简介

snip-ocr 是**完全离线**的 Windows 桌面截图工具：主窗口 + 托盘常驻，按快捷键框选，松手后可复制、存 PNG、贴成置顶浮窗，或本地识图取字。

全程不访问网络、不需要账号，配置只写本地 `data\config.json`。

### 不适用场景

- 需要标注（箭头/马赛克/文字）、截图历史、自动更新：不提供；贴图历史（最近 50 条）见 3.6。
- 手写体、竖排、低对比度艺术字：系统 OCR 不擅长，需人工复核。
- 跨多显示器一次拉框：不支持，只能截鼠标所在屏。

## 2. 安装与构建

### 2.1 直接安装

1. 双击 `snip-ocr-Setup-0.1.0.exe`，或运行免安装版 `snip-ocr-Portable-0.1.0.exe`。
2. 首次运行 Windows SmartScreen 提示时点「更多信息 → 仍要运行」（未签名，属预期）。
3. 启动后显示主窗口；关闭主窗口会隐藏到托盘。彻底退出可用右上角电源菜单，或托盘右键菜单。

### 2.2 源码构建

```bash
npm install
npm run icon       # 重新生成安装图标与托盘图标
npm run dev        # 开发模式，显示主窗口
npm run build      # 类型检查 + 构建 out/
npm run selftest   # 自动化验收（会真实弹遮罩）
npm run dist       # 只解包，快速验证打包
npm run pack       # 安装包输出到 dist/
```

**预期结果**：`npm run selftest` 末行 `[selftest] ALL PASS`（开发态实测 100 PASS + 7 INFO；打包版 90 PASS + 7 INFO）。

## 3. 快速开始

### 3.1 截图并复制

1. 主窗口点「点击截图」，或按 `Alt+A`。
2. 拖动框选，松开。
3. 工具栏出现：**OCR / 贴图 / 另存为 / 长图 / 取消 / 确定**。
4. 双击选区内部即可复制到剪贴板；也可在工具栏点「取消」关闭。

### 3.2 保存

框选后点「另存为」→ 系统对话框 → 默认文件名是时间戳 PNG。

### 3.3 贴图

- 点「贴图」生成贴图浮窗；「确定」只复制到剪贴板并关闭遮罩。也可用 `Alt+P` 贴最近一次截图。
- 初始尺寸与截图 1:1；拖拽移动、8 向改窗口大小、滚轮缩放窗口内图片、双击/Esc/悬停 × 关闭；多张可并存。

### 3.4 OCR 取字

1. 框选后点「OCR」。
2. 遮罩保持打开，OCR 侧栏会自动出现在选区的另一侧，先显示「正在识别中…」；识别中不能重复点 OCR。
3. 完成后文字进入可编辑文本框，底部显示字数；点「复制」才写入剪贴板。
4. 点 × 或按 Esc 关闭侧栏（遮罩仍在，可继续另存/确定/取消）。

### 3.5 长截图

1. 框选固定区域后点「长图」，遮罩收起。
2. 手动向下滚动页面，停稳后再按截图快捷键；程序会重画上次选区并追加新的一段。
3. 按钮变为「继续」，尺寸徽标显示「长图 · 第 N 段」。
4. 点「确定」= 拼接后复制；「贴图」= 贴拼接结果；「取消」/Esc = 丢弃全部帧。

仅支持纵向、单屏、手动滚动；长图态不支持另存为与 OCR；最大高度 20000 物理像素，超出会明确报错。

### 3.6 贴图历史

- 每次贴图成功后自动记录一条（原图、缩略图、时间、像素尺寸），默认保留最近 50 条，超出淘汰最旧。
- 主窗首页点「贴图历史」打开列表：可点击重新贴出、单条删除或清空全部。
- 数据在 `data\pin-history\`，与 `data\pins\` 临时图分开；退出应用不会清空历史。

## 4. 主窗口与设置

主窗口标题栏左侧为品牌字标与版本号；右侧依次为设置、电源菜单（隐藏到托盘 / 退出）、最小化、关闭到托盘。首页显示快捷键就绪状态、本地 OCR/零联网提示、贴图数量/确定复制/贴图快捷键规格条，并提供「贴最近一张」「打开设置」和底部托盘提示。

设置以主窗内整页打开，左侧为分类导航，分三个分类：

1. **快捷键**：截图快捷键 / 贴图快捷键；录制后点「应用」，失败会显示红字并禁用该组合的应用按钮；可恢复默认。
2. **通用设置**：开机自启（仅安装版生效）、检查更新（离线显示当前已是最新版本）。
3. **图标定制**：默认线框 / DeepSeek 大肥鱼 / 菲比丘比 / 自定义上传（PNG/JPG/WebP，≤5MB）。顶部有 6 图标工具栏预览，可一键恢复默认。

## 5. 贴图操作

| 操作 | 方式 |
| --- | --- |
| 移动 | 拖动浮窗任意位置 |
| 调整窗口大小 | 拖 8 个边缘/角 |
| 缩放图片内容 | 滚轮（0.25×–8×，以光标为锚点），顶部测量条显示尺寸与百分比；`Ctrl+0` 回到 100% |
| 关闭单张 | 悬停点右上角 ×（默认可见），或双击，或聚焦时按 Esc |
| 关闭全部 | 托盘右键「关闭所有贴图 (N)」 |
| 多张并存 | 支持；每张有独立 × |

悬停时显示 PIN 测量条（尺寸、缩放百分比与关闭入口）；贴图不持久化，退出应用即消失，临时 PNG 会清理。

## 6. 快捷键

| 动作 | 键 | 可修改 |
| --- | --- | --- |
| 唤起截图 | `Alt+A` | 设置 → 快捷键 |
| 贴最近一次截图 | `Alt+P` | 设置 → 快捷键 |
| 取消截图 / 关闭侧栏 | `Esc` | 固定 |
| 复制选区 | 双击选区内部 | 固定 |
| 关闭贴图 | 双击 / × / 聚焦时 Esc | 固定 |

快捷键写入 `<安装目录>\data\config.json`（Portable 为 exe 旁 `data\config.json`）。

## 7. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Alt+A` 没反应 | 被其它应用占用 | 设置里换 `Ctrl+Alt+A` 等 |
| 主窗口找不到 | 被关闭到托盘 | 托盘右键「打开主界面」 |
| 托盘图标找不到 | 被 Windows 折叠 | 展开通知区/设为常驻 |
| OCR 失败/乱码 | 系统无语言包，或小字/艺术字 | 安装系统 OCR 语言；放大后重试；人工复核 |
| 识字后剪贴板没变 | 设计如此，侧栏不自动复制 | 在侧栏点「复制」 |
| 确定后没有贴图 | 「确定」只负责复制，贴图是独立动作 | 点工具栏「贴图」，或按 `Alt+P` |
| 卸载后 C 盘残留 | 正常不残留 | 安装目录（含 data）与 `%APPDATA%\snip-ocr` 都会被卸载器清理 |

## 8. 安全与限制

- 不访问网络、无账号、无授权校验；OCR 本地执行，不上传截图。
- 剪贴板可能被其它应用读取；复制敏感内容后请及时清理。
- 只能截鼠标所在显示器；无标注、无截图历史（只有贴图历史）、无自动更新。
- 检查更新为离线「当前已是最新」，不伪造新版本。
- 未签名：Windows SmartScreen、macOS 未公证。
- OCR 依赖系统语言包，关键文字需复核。
- 分数缩放下贴图落点可能偏移 ≤2 DIP；图片尺寸严格 1:1。

## 9. 附录

### 9.1 配置文件

路径：`<安装目录>\data\config.json`（Portable 为便携 exe 旁的 `data\config.json`）

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `hotkey` | string | `Alt+A` | 截图快捷键 |
| `pinHotkey` | string | `Alt+P` | 贴最近一次截图 |
| `iconTheme` | string | `default` | `default`/`deepseek`/`chibi`/`custom` |

### 9.2 命令

| 命令 | 作用 |
| --- | --- |
| `npm run icon` | 重新生成安装图标与托盘图标 |
| `npm run dev` | 开发模式（主窗口） |
| `npm run build` | 类型检查 + 构建 |
| `npm run selftest` | 自动化验收 |
| `npm run dist` | 只解包，快速验证打包 |
| `npm run pack` | 安装包（→ dist/） |
| `snip-ocr.exe --settings` | 启动并打开设置 |
| `snip-ocr.exe --selftest` | 对打包产物验收 |

### 9.3 反馈

问题反馈请附：版本号、Windows 缩放比例、`npm run selftest` 末行输出；OCR 问题另附截图样张与系统语言。
